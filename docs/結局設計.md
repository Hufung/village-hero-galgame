## 1. Bad End ×2

### BE1 「故鄉的二次火海」
- **條件**：ch7 選⑤擋在她前面（`gevan_wounded`）且 `intimacy < 60` 且 選①=留村（`chase=False`）
- **因果敘事**：他像五歲那次一樣獨自扛，她像父親一樣戰死。村莊二度火海——本次件正是原文「害怕悲劇重演」的兌現。
- **內容**：10–12 分鐘。格凡重傷醒來，村口重建的木柵欄掛著那把刺劍。無 BGM，只有風聲。尾屏一行：「勇者守住了村口。這次。」
- **提示設計**：選⑤前若 intimacy<60，加一拍詩盈台詞「……你今天的站位，像會把命留給別人的人。」（玩家回放時會懂）

### BE2 「深淵之弓」
- **條件**：`chapter4_locked`（ch4 三連 miss）＋ ch7 未達成任何親密度事件
- **因果敘事**：她從不信任任何人把後背交出去——所以她獨自射封漩渦，一去不返。冰山線未化 = 她仍然把所有人鎖在牆外，包括求援。
- **內容**：8 分鐘重刀。神弓的光箭消失在漩渦裡，黑靴收回去了——「不值得殺」。格凡保留了那張她沒收回的弓弦。
- **可回退**：通關後章節跳轉回 ch4 練習室即可改命（引擎用 Ren'Py rollback + 章節選單）。

> ⚠️ 待決：BE2 死女主會趕走部分玩家。備選降壓方案——她唔死，入漩渦失联（留返 True 線救回她的口），我**建議用失联版**，死版收做 Hidden「if replay」。你拍板。

## 2. Normal End 「雨停之後」

- **條件**：守住村莊（ch7 存活）但 `dream_count < 3`（謎團未解）
- **內容**：漩渦被擊退但沒被關閉；帝國封詩盈襲擊勳章（諷刺呼應她那句「我不需要英雄」——她這次自己受勳，台下笑得很淡）；她返首都處理家務事，學期結束。
- **尾場**：車站，她塞回第 5.5 章那把雨傘：「說好還你的。」「傘還了。人欠你的。」列車開走。——恋爱成立、未來開放、哥哥線懸空。**Normal = 讀者會想打 True 的那種不甘**，钩子做足。

## 3. Good End 「雙劍的約定」

- **條件**：`hug`＋`indirect_kiss`＋`intimacy ≥ 85`，但選⑥未開（`dream<3`）
- **內容**：她父親的勳章由他陪她掛回家祠；两人把「依靠」說破：「以後你隨時找我」由她說出口（第4章台詞鏡像反轉——**全作最重要的一句角色完成度對白，誰說出口決定結局檔位**）。戰事只在尾屏字幕推進（暗湧留 White 版），哥哥線不揭。
- **與 Normal 的差別**：Normal=关系開放式；Good=关系完成、世界未救。

## 4. True End 「雙生琥珀」

- **入場券**：`hug`＋`intimacy ≥ 85`＋(`pet_shima` 或 `justice`)＋`dream_count = 3`＋`mask_seen`→ 選⑥可見「……哥哥？」
- **設計核心（依賴待決B）**：
  - **若 B 成立（王=哥哥）**：喊名≠戰鬥。琥珀雙生共鳴——他的碎裂 vs 格凡的溫潤。詩盈那句「我不需要英雄」在此回收：格凡拒絕殺「英雄」，寧要活嘅家人 → 哥哥瞳孔紅褪半秒（唔一次救贖，留人味），二人合力把漩渦**反封**而非關閉：「下次見面，我哋會揸住贏。」（ sequel hook 有底氣）
  - **若 B 否**（備選：荒原血人=哥哥寄靈）：True 改「琥珀寄靈安息線」，結局尾場哥哥聲音隨琥珀碎光散咗——刀但不破恋爱。
- **尾場**：村莊第三場重建（木柵欄第三次立起，村民已經識得釘哪根樁）；田間 CG（資產清單既有）；詩盈用「喂」喊他（稱呼演化表終點）。
- **長度**：第 8 章正文 + 約 40 分鐘，唯一帶全 CG 的結局。

## 5. Hidden End ×2

### H1 「村莊勇者」（Solo/反恋爱）
- **條件**：全程 intimacy < 20（D 節全部冷淡選項）＋ ch7 選⑤自動站位
- **內容**：他做回第一章的自己——田間、清風、破舊柵欄。最後一鏡同第 1 章開場**逐幀鏡像**，只有馬背上多左一袋詩盈留低嘅果乾（玩家自己發現，無台詞）。——「不是所有問題都值得寫程式解決」嗰種成熟，男主線版本。
- **價值**：成本最低（重用第一章資產），_completionists_ 最愛。

### H2 「詩瑪之夢」（喜劇/世界觀彩蛋）
- **條件**：`pet_shima` ＋ 其他結局通晒（6/6 圖鑑格）
- **內容**：3 分鐘 Q 版。詩瑪 POV：養育兩個兩腳獸（格凡同詩盈）的生態觀察報告，吐槽萬劍法打飛曬布。尾句正典化詩瑪設定（雙界守望生物）——輕鬆反調，平衡 BE2 嘅刀。
