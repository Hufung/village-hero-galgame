## 1. 作品定位

- **類型**：劇情向恋爱 galgame（奇幻熱血 + 冰山系女主）＋戰鬥演出
- **基調**：70% 校园恋爱日常 + 30% 雙界史詩戰爭；核心情感軸＝「兩個失去至親嘅人互相治癒」
- **目標平台**：Ren'Py 8.5.x（desktop + Android/Web build）— 引擎自帶 save-anywhere/backlog/skip/auto，唔使重造
- **時長目標**：一周目 6–8 小時；三條路線 + 2 個結局缺口
- **對標**：《美少女萬華鏡》(演出) × 《可塑性記憶》(世界觀密度) × 《CLANNAD》(家族/喪親主題)

## 2. 世界觀（正典整理）

### 2.1 雙宇宙
| | 本宇宙 | 其宇宙 |
|---|---|---|
| 基調 | 和平、繁衍、劍術與神器 | 鐵血、冷酷勢力統治 |
| 勢力 | 帝國（首都布魯比斯）、起學堂 | 獨克加王、阿爾克斯族、魯加族 |
| 侵略 | 被入侵方 | 喚魔者（先鋒）、惱鬼（空中/鑽地）、衛道者（重裝）—「金宇計劃」核心能源提煉中 |

### 2.2 力量體系
- **劍術**：格凡自學「萬劍法」（劍氣可傷虛化體惱鬼）→ 皇級神器「七彩雙劍」入手後進化終式
- **神器**：神界日於「神台」引導血脈本源幻化；品質分級（皇級=最頂）；只可經起學堂合法取得
- **詩瑪**：珍稀溫順生物，因都市化+魔物被逐出家園 → 世界觀溫度計，做隱藏支線（見 §5.3）
- **守護魔瓶**：學院發放，碎瓶＝頂尖強者透過傳送陣即時支援（每週目最多用一次，戰術資源）

### 2.3 地理
橡樹山林石屋（格凡隱居地）→ 故鄉村莊（雙重創傷地）→ 首都布魯比斯（千米金色城牆、紅石起學堂）→ 荒野（詩瑪棲地）

## 3. 角色檔案

### 格凡（男主，視角人物）
- 15 歲「村莊勇者」，5 年前家園被毀（5 歲喪雙親），哥哥下落不明，胸口琥珀=唯一信物+噩夢開關
- 性格：沉靜滄桑、自謙低調；獨白風格克制、少量自嘲；**面對詩盈時緊張但真誠**
- 秘密：四歲生日河灘拾得**兩塊一體雙生琥珀**（兄弟一人一塊）；偏頭痛+不屬自己嘅記憶碎片（白骨荒原、抱女哀嚎嘅血人）
- 寫作規則：從唔講「我會保護你」呢類大話；用行動同追問表達關心

### 詩盈／雅盈（女主）
- 白髮刺劍少女；帝國將領之女，母親產亡；父親戰死守村（第 2 章救格凡=祭父回程）
- 校內用名「詩盈」，真名「雅盈」——**叫錯名=關係未夠，「雅盈」係親密度里程碑**（第 4 章告白後先知道）
- 冰山系：短句、禮貌疏離（「舉手之勞」「直走，右轉」）→ 融化後先有長句同自嘲
- 武藝：帝國軍式刺劍（父親教的）；深夜自虐式加練＝創傷發洩
- **待決 A**：武器一致性（第 2 章刺劍、第 7 章神弓）。建議設定：神器於神界日覺醒＝破邪神弓；平民用父親遺贈刺劍；對白要點破（「弓係血脈畀嘅，劍係爸爸留返嘅」）

### 獨克加王（反派／暗線）
- 黑曜石皇座、面具、通紅瞳孔；鐵腕抹殺前代國王勢力；掌中**破碎琥珀**（與格凡嘅雙生琥珀呼應）
- 台詞風格：三句內解決一切（「拉出去」「『那件事』準備得如何」）；唯獨摘面具後先有內心戲
- **隱藏設定（真路線爆雷，企劃層面先寫死）**：獨克加王＝格凡失踪嘅哥哥（被其宇宙吞噬/奪舍，琥珀裂痕=記憶裂縫）。若你唔想要血親反轉，備選：哥哥係琥珀中封記憶嘅「荒原血人」（第二爆雷層）。**待決 B**，由你拍板。

### 配角群
- 村民（歡迎回鄉嘅暖場）、守衛隊長（怯但盡責，第 7 章同格凡並肩）、班主任（工具人）、阿爾克斯族親信（反派傳話）、僕人（詩盈童年回憶旁白）

## 5. 對白規格（VN 寫作規則）

1. **一行一拍**：單句 ≤45 字；長情感句拆三行，中間插 `(click)` 留白
2. **詩盈台詞公式**：疏離期＝名詞句+省略號；融化期＝開始出現「……嗯」「才、才不是」；崩坏期（第4章哭訴）＝全作唯一一段長獨白，之後永久縮短返
3. **格凡獨白**：唔講道理，講身體感覺（掌心汗、握繩發白、喉嚨乾）
4. **战斗演出**：招式名用「」；每段砍殺後留 1 句喘息對白，防止文字牆
5. **間接接吻名場面**：寫「動作+音效符號」（吸管的輕響、耳根漸紅描述），詩盈台詞全部短、斷
6. 稱呼演化表：格凡眼裡 `白髮少女→詩盈同學→詩盈→雅盈`；詩盈眼裡 `格凡同學→格凡→（真路線）喂`（最後反而係最親）
7. 待決 C：旁白人稱——建議格凡第一人稱（原文全知 POV 屬小說，遊戲要收斂；其宇宙場景改「靜畫面+字幕」卡過場）
